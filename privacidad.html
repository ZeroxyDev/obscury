Política de privacidad de rush studio

Última actualización: 8 de noviembre de 2026.

rush studio es una herramienta de uso personal: la usa solo el autor del canal Obscury para gestionar su propio canal de YouTube. No tiene otros usuarios.

Qué datos usa

Con el permiso que da el propio autor mediante Google, la herramienta sube y programa vídeos, actualiza sus títulos, descripciones y miniaturas, gestiona listas de reproducción y comentarios, y lee las estadísticas de su canal a través de las API de YouTube.

Dónde se guardan

Los datos y el token de acceso se guardan solo en el ordenador del autor. No se venden, no se comparten con terceros y no se usan para publicidad.

Cómo retirar el acceso

El acceso se puede revocar en cualquier momento desde myaccount.google.com/permissions.

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.
